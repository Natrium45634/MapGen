# MapGen — генератор физико-географических карт по сиду

Windows-приложение (C++20, Qt 6) для воспроизводимого построения детализированных
физико-географических карт землеподобной планеты. Карта возникает из причинной цепочки
«плиты → кора → рельеф и батиметрия → уровень моря и берега → циркуляция и климат →
гидрология → биомы и высотная поясность → вулканизм».

Статус: разработка по ТЗ v1.0, фаза за фазой (см. `docs/PHASES.md`).

## Быстрый старт (сборка)

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build --output-on-failure
```

Windows-сборка, установщик и portable zip собираются в GitHub Actions (`.github/workflows/build.yml`).
